# Conector de catálogo para WordPress

Instalado y activo en novogensalud.cl el 28 de octubre de 2026. El shortcode [novogen_connect_catalogue] está incorporado en la página Servicios (ID 13139).

Lee https://novogen-connect.vercel.app/api/catalogue?slug=novogen. No requiere claves de Supabase. Refleja los cambios publicados del CRM después de hasta 60 segundos. Los agrupadores contienen opciones; solo los servicios individuales tienen un enlace de solicitud.

Para instalar una copia en otro entorno: subir este ZIP desde Plugins, activarlo e incluir el shortcode en la página elegida. No modifica páginas automáticamente ni reemplaza Agenda.

Para revertir en novogensalud.cl: restaurar el respaldo del contenido anterior de la página Servicios y desactivar el plugin. Desactivarlo sin retirar el shortcode dejaría visible el texto del shortcode.
